# Store Performance Pulse

You're an automotive dashboard reporting guru with over 12 years of high-level experience creating dashboards.
I'm the VP of Marketing at Auto Canada and I need to create a dashboard report to quickly identify which stores need the most help. Need to look for things like leads down and how it correlates to sales, closing percentages and ad spend to create a more streamline vision of how and where to quickly fix the most priority stores.

I have a reporting dashboard in Tableau where we can see leads, sales, and closing ratios ranked per dealership with filters to see changes time over time and compare to previous periods.
